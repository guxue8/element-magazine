# 战斗实现验收记录

- 实现文件：`src/combat.js`（纯结算与帧快照）、`src/combat-effects.js`（113 个真实卡牌分派、方向、卷轴）、`src/combat-bonds.js`（53 基础羁绊和 8 进化事件）。
- `resolveRound` 克隆输入；不推进战役回合、增援或固定收入。输出状态、独立战场帧和本轮伤害摘要。
- 已接入：实体计时、共享额外推进、回响隔离、全部伤害形态、状态与控制抗性、3 种造物及变体/容量/替换/指令/自然退场、敌人行动、击杀货币、首领记录、天赋修缮和应急护板。
- 附魔使用 `temp.loadedMark` 与 `temp.loadedLurk` 装填快照；卷轴给下次装填写 `temp.magnet` / `temp.lurk`。G03 蓄能和 G05 回收保存在槽位。
- 进化阶段在回合开始读取，成长回合末提交，每条每轮最多 3、总计最多 9。源卡和元素资格均校验。
- 资源收益共享刷新 +2、删除 +3 上限；自然退场与替换分开；反击机会与指令行动各有统一计数器。
- `implementedBulletIds` 覆盖实际分派的 105 常驻与 8 消耗卡，不以通用伤害占位。

## 验证

`node --test tests/combat.test.js`：200/200 通过（当前记录）。包括 113 卡逐项确定性/有限状态检查、61 羁绊高阶段健全性检查、26 项时序与数值回归。

回归覆盖：输入不变、帧独立、计时未入夹冻结与无目标零保持、造物替换和寿命、提前左向卷轴、控制隔回合、实际击杀发奖、回响不复制附加效果、资源共享上限、额外推进、槽位蓄能、最近目标与优先目标区别、连发承接穿云、伤害一次取整、进化成长下回合生效、替换不自然爆破、卷轴消耗前门槛锁定、条件原生击杀、共享反击池、指令不重复正常羁绊、自毁不发奖、回响首领击杀修缮。

所有条目都有实现；健全性 smoke 不等于所有卡牌组合都已穷举，也不证明数值平衡。尚未做独立的完整游戏手动试玩，战役/UI/存档由对应模块负责。
