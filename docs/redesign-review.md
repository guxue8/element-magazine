# 战场界面重做独立审查

日期：2026-10-26。审查范围为 `src/app.js`、`src/view-utils.js`、资源上限与存档兼容，以及相关 CSS 规则。本审查没有修改应用逻辑或样式；新增的验证位于 `tests/ui-contract.test.js`。

## 已发现并修复的回归

- 「准备预案」天赋仍可购买，初版新界面却没有调用 `rerollStart` 的入口。主实现已在符合条件的背包面板恢复重抽按钮。测试验证按钮可用、仅重抽四枚起手、无招募扣费、使用后入口消失。
- 一次性卷轴的详情原先只有通用消耗说明，缺失与当前弹夹布局相关的无收益提示。主实现已补恢复 `scrollWarning`。测试验证 C01 左边界提示以及换位后消失；C05 在自然减计时后是否还能额外推进的预警与真实战斗结算一致。

上述修复后，在审查覆盖范围内未发现阻断运行或明显丢失主要交互的缺陷。

## 其他检查与边界

- 战斗播放期间最终结算状态先持久化，画面播放使用前态及帧快照；`committed` 防止播放期间保存覆盖结算结果。游戏修改操作受 `busy` 限制，阅读面板仍可打开。
- 奖励选择、跳过、刷新、事件转卷轴、附魔目标选择和下一批预览保留原有游戏动作路径。
- 敌人坐标由实体标识和通道稳定决定，不依赖数组序号；击杀其他敌人不会使剩余实体重新排队。
- 横屏小尺寸样式与竖屏提示覆盖存在；实际浏览器的布局、素材可见性、横屏交互与动画由主实现执行单独验收。上述 Node 测试使用最小 DOM 外壳，不代表浏览器排版或视觉验收。
