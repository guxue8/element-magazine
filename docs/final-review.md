## 已发现并处理的问题

1. **P2：回路事件的卷轴被误当成附魔。** 原 `normalize` 在 `enchant` 事件中仅查附魔目录，第三张卷轴丢失名称、描述与 `trigger`，点击后误开目标选择。UI 实现者已增加子弹目录回退；审查复读确认修复。UI 实现者另报告使用实际模块 DOM smoke 验证 `['M03','G03','C05']` 的卷轴可以直接领取。
2. **P2：损坏存档可通过校验后使继续游戏崩溃。** 独立复现：合法新局拥有 `S01`，删除 `evolutions` 字段，原 `saveGame` 和 `loadGame` 均无警告；继续时侧栏访问 `run.evolutions[id]` 抛错。主代理已补充必需结构、统计数值、候选引用、事件与未来通道校验，并新增回归测试。复核后该类存档会拒绝、备份并保留合法局外数据。
3. 主代理先行发现的攻击印记纯召唤排除、首胜奖励展示及首领击杀治疗重复问题未重复计为本审查发现。当前相关代码已采用合法攻击目标检查、奖励凭据及战斗中立即治疗。

## 未发现问题的重点路径

- `busy` 在开始执行时同步设置，阻止重复执行和会修改/保存当前局的 UI 操作。最终战斗结果先保存，动画只暂用旧状态展示；暂停或倍速不重新结算。
- 付费选择/刷新先扣资源，跳过不退款；阶段选择机会经处理记录去重。
- 删除仅移除指定实体；休止槽冻结，取消休止恢复原实体；不放回抽取不重复实体。
- 旧敌与新批次并存，18 批之后只推进战斗回合；阵亡先终止后续敌方攻击，局外结算按局 ID 去重。
- 羁绊以已选择且背包数量满足为前提，卷轴本回合消耗不提前改变已锁定的门槛。
