# 战斗反馈与第二轮试玩调整

**目标：** 将射击、爆炸和敌方行动统一为奇幻像素表现；进化羁绊补赠缺失的核心弹；增加可击破的敌人并适度降低初征压力。

**实现边界：** 保持整夹一回合、不清场也出下一批、不放回装填、元素禁用规则。保留单条红色怪物血条、简洁状态图标、现有背包和天赋入口。只修改当前项目，不改系统或代理设置。

- [x] 进化羁绊：候选资格不再硬性要求已有核心弹；确认选择时若背包没有该种弹，赠送一枚正常实例；已有则不重复赠送。跳过不赠送，其他激活需求仍有效，禁止元素不能绕过。
- [x] 难度：新增遭遇版本，增加脆弱杂兵，降低普通怪和首领生命、初征攻击压力；旧局保留原遭遇配置。使用全程模拟比较击杀量、胜率和剩余生命，检查更高难度仍递增。
- [x] 敌方行动：战斗帧记录移动起终点与攻击者；在不额外改变战斗规则的前提下，同组移动一起播放。近战突进、远程弹道、治疗/鼓舞有不同反馈；倍速、暂停和减少动态效果可用。
- [x] 像素特效：阶梯形弹头和尾迹、方块闪光与分层爆炸，按元素区分颜色和形状，去除圆形光环、模糊光晕和文字符号爆炸。
- [x] 验证：规则回归、全套测试、静态构建及桌面/手机横屏试玩；检查存档和新模块部署清单，记录结果。

文件分工：campaign.js 及进化测试负责赠送；difficulty.js/storage.js 及难度测试负责新遭遇；combat.js 及敌方帧测试负责行动数据；battle-feedback.js/app.js/playtest.css 负责展示与播放。子任务完成后统一审查和集成。

验证完成：369 项测试、600 局平衡对照、静态 HTTP 检查通过；桌面与横屏的命中、同步推进、远程受击、暂停和倍速已实测。结果见 docs/combat-polish-report.md。
