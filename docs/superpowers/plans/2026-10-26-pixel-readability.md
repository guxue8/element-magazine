# 像素战场与简洁构筑描述 Implementation Plan

> 用户于 2026-10-26 指定方向并明确继续。采用 subagent-driven-development 并行执行独立任务，主线程整合与浏览器验收。

**Goal:** 改为统一的侧视 2D 奇幻像素风，以一条战线显示敌人；缩短羁绊描述。先研究成熟肉鸽，再审视贯穿各品质的单体、群攻、状态、召唤与辅助选择。

**2026-10-26 最新优先级：** 用户明确“群攻不一定只在低阶，先去学习其他完善的肉鸽游戏的思路”。先完成有来源的研究与现有内容审计，再确定平衡方案。工作区此前写入的五枚低阶群攻改动是候选，不能当作已定稿的全品质方案。

**Architecture:** 保留 catalog 的精确机制说明，新增展示文案层（短效果、关键词、成长摘要），完整规则折叠。用本地透明精灵图替换角色和怪物图标。作战距离统一为水平距离，视觉重叠不改变位置或伤害计算。

**Tech Stack:** 原有零依赖 ES Modules、HTML/CSS、Node 测试；本地 PNG 图集与相对路径。

## Global Constraints
- 保留 3×4 不放回弹夹、候选跳过、存档、18 批增援、53+8 羁绊和 105+8 子弹的数量。
- 子弹图标点击详情、背包/设置/图鉴图标入口、横向充能条、删除/换位三次上限不回退。
- 文案不删改机制：展示一句核心效果，独立显示条件，复杂限制折叠；不能删掉次数上限而导致误导。
- 像素素材本地保存，透明角色须保留 alpha；不用旧剪影叠在写实背景上的组合。
- 单线敌人允许水平重叠；精灵脚底落在同一地面。重叠目标仍可从敌人情报面板选中。
- 群攻不限制于白/绿品质，也不要求所有子弹都具有群攻。按目标选择、覆盖范围、状态传播、触发方式、可靠性与代价区分用途；高品质允许直接而强力，低品质保留可成长的用途。数值须在单体、密集、分散与混编敌群中验证。
- 不发布远端、不重置用户存档。已有通道字段可以保留兼容，但单线战斗不再以通道制造不可见的距离。
