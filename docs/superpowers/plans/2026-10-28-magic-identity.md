# 角色、法术分工与长期成长

用户反馈要求直接改进六项：统一并重做主角、召唤物实体像素表现、群攻与单体平衡、大型独立魔法视觉、扩展天赋树、参考杀戮尖塔重新编辑文本。

- 美术使用同一新像素素材的待机/施法姿态，封面/头像/战斗共用；泉灵、岩卫、礁炮改实体素材。水龙、岩石法相为独立大型魔法形态。
- 表现按魔法类型选择天降落雷、龙形冲击、法相重击、陨火及旋风，保留实际目标、范围和伤害事件；减弱动态模式保留读数。
- 平衡保留范围全命中，但拉开主目标与周边伤害，以单体/首领、三敌和密集群基准检查优势，保留长蓄力收益。
- 扩展天赋节点与后期机制，核算获取节奏；已有投入保留，不因改价刷返还点数。
- 文本使用固定触发词、动作与数值顺序、统一关键词解释。主文本直接写伤害数值，补充边界留在完整规则；参考 Mega Crit 官方 Weekly Patch 44 和 V2.2 的措辞统一及描述执行顺序原则。

验证：机制测试、老存档/退点兼容、整局模拟、桌面/横屏截图、角色素材边界与透明度、静态子路径和线上部署。
