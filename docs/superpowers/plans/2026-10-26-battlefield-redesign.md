# 全屏战场与图标交互 Implementation Plan

> 执行方式：superpowers:subagent-driven-development；用户已于 2026-10-26 明确继续已记录重做方案。

**Goal:** 以奇幻场景占满一屏，中央偏下固定 3×4 图标弹夹；点击子弹才展示详情，背包/图鉴/设置按需展开，支持手机横屏。

**Architecture:** 保留 catalog/campaign/combat 的结算协议，重写 app.js 展示与 style.css。图标由本地 art.js 统一映射，角色在世界空间自然分散。独立修改资源上限并保留旧存档。

**Tech Stack:** 零依赖 HTML/CSS/ES Modules、Node 内置测试、本地 SVG 图标与生成的场景图片。

## Global Constraints

- 背包、设置、图鉴、天赋、战报不常驻占据场地；功能仍可从图标访问。
- 子弹格仅保留图标、品质边框、计时/印记小标；点击浮层显示名称、完整效果、附魔及抽取权重。
- 主角左侧，敌人右侧向左推进。采用可复现的自然散布坐标，视觉位移不能改变逻辑位置/通道，不做垂直堆叠。
- 删除一次 30，换位一次 10；上限分别 90/30，图标内三段槽显示次数和进度。购买无新增上限。
- 主界面无纵向滚动；手机横屏，竖屏显示旋转提示；弹窗内部可滚动。
- 保留一次性卷轴、附魔、羁绊、付费跳过、存档锁定、奖励去重等完整流程。
- 保留 GitHub Pages 相对地址和离线本地素材，不运行外部图片热链。
