# 魔法与密集怪群改造

用户已要求实施五项修改，保留原本的编排、抽取及回合规则。

1. 范围爆炸覆盖爆心半径内全部敌人；保留穿透、连锁的不同规则，合并爆炸播放，显示覆盖范围与同时受击。
2. 新远征版本增加脆弱小怪，降低整波生命预算与攻击压力；旧远征保留原波次版本。对照固定种子模拟，不将机器人通关率当作玩家通关率。
3. 表现词汇统一为法术、法阵、蓄力；不变更存档 ID。按品质增加聚能、法印、落雷或冲击层次，保留像素轮廓和减弱动态效果设置。
4. 逐项审核蓄力收益，低阶尽快发挥作用，高阶以群体范围、召唤和高威力回报等待。
5. 部分一次性卷轴留下本局永久的实例强化，限制叠加；详情显示效果，保存读取后保留。

验证：范围边界与多人命中、计时收益、实例强化与存档、波次版本、全套测试、静态子路径构建、桌面与横屏浏览器验收。
