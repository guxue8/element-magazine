# 界面重做要求与暂停记录

当前状态：用户于 2026-10-26 明确继续，重做已实现并完成本机验收，等待试玩反馈。以下暂停内容保留为历史记录。

## 用户最新反馈

当前界面复杂、臃肿，人物和怪物的视觉效果不符合预期。恢复后按下列方向重做，不能把当前界面视为已获认可的成品。

1. **战场成为整个主界面。** 设计奇幻战斗地点的背景、设施等环境内容，使玩家直接面对完整场景。
2. **弹夹放在主界面正中偏下。** 保留 3 行 × 4 列的玩法结构，融入战斗画面。
3. **收起背包。** 主界面仅放一个背包小图标，点击后展开背包信息。
4. **功能入口图标化。** 设置集中到设置图标；图鉴用小书图标；减少常驻文字、面板和信息堆积。其他复杂内容按需展开。
5. **怪物自然分布。** 不要堆成一团或刻意叠放；允许正常的局部重叠和遮挡。不能只靠给同格图形微小错位来视为满足本要求。
6. **替换角色与图标素材。** 恢复后搜寻合适的奇幻风格人物及图标，尽量用于主角、怪物、子弹、羁绊，并保持风格统一。当前简陋人物造型需要重做。使用时记录素材来源与可用许可。
7. **购买、删除、换位采用较大的图标按钮。** 用图标内部的条数展示可用次数，减少纯数字资源栏；删除最多储存 3 次，换位最多储存 3 次。购买的储存上限没有指定，不擅自套用 3 次。
8. **手机采用横屏布局。** 恢复时以横屏游玩为目标，不沿用当前竖向长页作为手机主要体验。

以上为已确认的重做方向，不在暂停期间进一步实现。现有核心玩法与已确认内容池继续保留；如重做涉及机制变化，恢复后再讨论。
